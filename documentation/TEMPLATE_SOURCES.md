# Project-page design references

Reviewed on 2026-09-21:

1. Nerfies (ICCV 2021): https://github.com/nerfies/nerfies.github.io and https://nerfies.github.io/ — centered title, resource links, visual teaser, abstract and research narrative. Upstream website license: CC BY-SA 4.0.
2. Academic Project Page Template: https://github.com/eliahuhorwitz/Academic-project-page-template — responsive academic project-page organization and accessibility. Based on Nerfies; upstream website license: CC BY-SA 4.0.

The local page borrows this organizational convention rather than claiming a CVPR/ICCV acceptance or copying the authors' visual results. HTML/CSS/JS were newly authored. No upstream code, images, analytics, author list, affiliation or BibTeX entry was copied. Attribution appears in the page footer and credits page. No template runtime dependencies are needed.

Manuscript illustrations and reported numbers come from this project's existing v7.70 materials. Author and publication metadata are intentionally absent until confirmed. A future public URL must not be presented as live before deployment.
