Planning code and data

GitHub repository · Frozen planning ZIP · 4.6 MiB · Code and evidence map

From the cloned repository, with Python 3.11 or later:

python tools/verify_archive.py
python tools/run_plan.py examples/tea_candidate.json --output local_runs/tea_result.json
python tools/check.py
cd reproduction
python reproduce_all.py results/new_run

When using only the planning ZIP, enter its ATG_reproduction_v7_70 folder and run python reproduce_all.py results/new_run from its root. Always choose a new output directory. The tea example is an interface illustration, not another experimental sample.

The three frozen evaluations contain 1,024 internal and 3,944 archived-tool setting records, 52 public-specification settings and 8,640 finite-mechanism settings. Setting records are not independent task counts. Reproduction compares stable outputs, not wall-clock timing. Historical MILP and timing dependencies are described in the code map.

Current simulation study

Interactive recordings · Code, models and 240 run logs · 93.6 MiB · 20 preselected videos · 15.5 MiB · Frozen study protocol

Eight templates, five initial-position seeds, 80 nominal full/serial runs and 160 stress runs: 184 completed and 56 failed. The 20 recordings illustrate preselected conditions; they are not the statistical denominator. All failed runs remain in the data. These are MuJoCo simulations using fixed skills, not hardware recordings.

python -m pip install -r simulation_expanded/requirements.txt
python simulation_expanded/run_expanded.py --output results/new_physics --workers 4 --videos
python simulation_expanded/verify_expanded.py results/new_physics
python simulation_expanded/planning_study.py --output results/new_planning

Run these commands from the repository root, or the directory containing simulation_expanded/ after extracting the expanded code/data ZIP. Video rendering additionally requires a working OpenGL environment and FFmpeg.

Interpretation and provenance

Accepted plans satisfy represented discrete states, capacity-one resources and L/R occupancy. B occupies both units. Rejection does not prove infeasibility, and formal acceptance does not guarantee physical success. The conversation-generated candidates, controlled perturbations, public source checks and physical simulations have different evidence roles.
