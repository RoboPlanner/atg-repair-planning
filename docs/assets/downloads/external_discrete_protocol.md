# 外部离散参考评价预先协议

## 来源与选择

1. AssemblyGrid_v1固定提交ce61f635e47d312d633eda022b5f08bc4dbe888f，原始全部10份配方JSON逐一检查。仅当全部操作的最小协作人数不超过2且没有未决排他路线时直接适配；不降低人数、不删除不适用操作凑出可行图。保留所有排除记录与原因。每个配方只有一份单产品记录，不扩增种子或重复产品数。
2. 同提交公开test_alternative_routes.py的_branch_recipe(False)提供独立的包容OR、多生产者规范用例。它是原基准明确标注的扩展测试，不并入官方配方分母；排他XOR对照保留为不适用性测试，不将其放宽为OR。
3. OR-Library jobshop1.txt中预先固定ft06、la01、la02、la03、la04、la05。保留原操作顺序、机器编号及持续时间，不按结果选择实例。仅增加本文要求的两个抽象通用执行单元，所有操作为single，Cand={L,R}；机器作为容量1资源。这是双单元受限离散投影，不复现原JSP最优值，不与原问题排行榜比较。

## 候选与比较

不调用模型，不伪称自然生成错误。配方候选仅按原文件显式predecessors建立完成事实的状态边；材料输入与输出字段原样映射，材料依赖、同步及资源顺序交给后处理。作业车间候选保留全部原作业链，机器顺序未定。这检验外部规范进入关系修复接口后的可恢复义务，不是随意从正确答案随机删边。

四种设置均读取完全相同的候选与S0/Sg：直接审计、一次字段匹配、一次字段匹配加同一压缩、完整方法。目标来自公开配方final_token或公开作业的末操作，不从候选最终输出推定。保留全部成功与失败结果。没有E_order时不声称测到压缩收益。

## 独立检查

另写检查器，直接读取冻结原始配方/作业矩阵及调度，不读取ATG的Pre/Post/Res来定义真值，也不调用被测审计函数。检查操作覆盖、原时长、原始材料消耗/生产、显式先后、OR/XOR条件、配方协作人数、原资源排他、实际L/R占用及外部规定目标。每次结束事件先于同一时刻开始事件处理。

原AssemblyGrid空间可达性、工具/技能、持物配置、搬运、故障、完整仿真成功率不在本投影内；假设两单元满足所需技能且原料已就绪。角色技能和几何不会被冒充为已验证。材料使用单产品操作序列进行独立消费检查，不将本文的无删除状态模型扩展成通用消耗规划器。

## 报告

主结果分别报告公共配方、公开OR规范用例和作业车间投影的适配覆盖、正式接受、独立离散语义通过、符号完工时间；不把它们混成一个机器人成功率。没有唯一资源定向金图时不以边集合相等惩罚合法替代定向。报告简单组合与完整方法逐实例差异，无显著性推断。

另以完整枚举的小规模机制用例及独立穷举可行顺序核验多生产者策略：属于作者构造的机制证据，与外部语义证据单列，不称独立工业任务。
