Preserved originals and verification

Canonical reproduction uses the unchanged original archives. They retain original-language task text, historical reports and report-generation code. English copies form a separate reading layer, with original and translated hashes and every dataset string substitution documented.

Dataset record ordering, JSON keys, node/edge/state/resource symbols, durations, schedules and numerical statistics are unchanged. Legacy keys such as title_zh are retained, while their translated values are English. Upstream licenses and attribution continue to apply.
