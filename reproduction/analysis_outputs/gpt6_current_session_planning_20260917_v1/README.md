# 当前会话 GPT-6 直接规划实验，24任务

先查看 `reports_v1/统计分析报告_24任务.md` 和 `reports_v1/任务规划全集_24份.md`。

六类任务各4份，共254个节点，含24个B节点。任务规格与候选由当前GPT-6助手直接编写，助手已知论文方法及验证代码。这是方法知情的当前会话候选接口试验，没有独立服务端API请求ID、外部金标准或硬件执行结果。

本批冻结原始候选后实际运行既有代码。修复前后均24/24形式接受、24/24严格调度接受、24/24日志重放一致。净关系变化为0；82条日志接受事件来自41条同步边的删除重建。相对相同节点完全串行基线，逐任务平均符号时长降低18.4861%，平均加速比1.2411。不能把此收益归于关系修复，不能把形式通过率写作语义准确率或recall。

## 文件

- `task_specs.json`：24份任务规格，显式S0、Sg和容量1资源。
- `common_prompt.txt`、`generation_protocol.md`：生成要求、来源与预定统计协议。
- `raw_candidates_*.json`：六组原始候选，每节点恰有九字段。
- `pre_generation_freeze.json`：生成前任务规格、协议与代码哈希。
- `candidate_freeze.json`：全部候选写完、评估前的原始文件哈希。
- `frozen_evaluator/`：当时既有实验代码的只读副本，未修改。
- `evaluate_batch.py`：固定适配与评估脚本，只重命名字段和单元标签。
- `results_v1/`：首次评估结果；每任务保留输入、审计、全方法及关闭压缩结果、全部事件和重放图。
- `verify_and_report.py`：不导入既有验证器的独立图、序列化调度和重放核查，生成报告。
- `reports_v1/`：报告、24份完整规划及调度、分域CSV、独立复核及合法串行基线。
- `artifact_manifest.json`：交付文件SHA-256，用于检查解压后的字节完整性。

## 复现

Python 3.10或以上，标准库即可。从解压后的本目录执行：

```text
python -B evaluate_batch.py --output results_reproduction
```

脚本校验输入、原始候选和源码哈希，并拒绝覆盖已经存在的输出目录。复现运行只重做确定性评估，不重新采样GPT-6候选。首次结果的时间戳与软件环境保存在`results_v1/run_provenance.json`。若需要再次生成报告，应使用目录副本；报告脚本也拒绝覆盖`reports_v1`。

## 解释边界

原始与后处理的六门结果属于已表示符号约束。I02等记录仍需要工艺语义复核：检测记录完成不等于检测合格，任务中也可能漏表示拆线等操作。原始记录为可审查实验输入，不是人工正确答案。没有独立参考图，不报告precision、recall或F1。

本批不包含连续碰撞、轨迹、硬件控制或算法运行时间测量；d为输入的整数符号时长。B同时占用L+R。既有代码序列化附加的workspace字段保留在代码输出中，原始候选仍严格为九字段。本轮未修改论文、原实验代码或历史实验。
